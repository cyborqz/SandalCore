# Security Policy

## Reporting Security Issues

We take the security of Sandal Core seriously. If you discover a security vulnerability or sensitive data exposure, please report it privately rather than creating a public issue.

### How to Report

Please report security issues using **GitHub Private Vulnerability Reporting**:
1. Navigate to the repository's **Security** tab.
2. Under "Vulnerability reporting", click **Report a vulnerability**.
3. Fill out the report form with full technical details.

### What to Include

To help us investigate and resolve the issue quickly, please provide:
- A descriptive summary of the vulnerability.
- Affected components (services, world daemon, networking library, or scripts).
- Step-by-step reproduction instructions or a minimal proof of concept.
- Potential impact and threat model.
- Any suggested remediations or patches.

### Please Do Not:
- Open public GitHub issues or discussions detailing unresolved security flaws.
- Include live secrets, real personal credentials, or external network attack vectors in public forums.

We appreciate your responsible disclosure and support in keeping the project secure.
